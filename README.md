# VFD_control_induction_motor

# Dynamic Simulation and Constant V/f Control of a Three-Phase Induction Motor

A MATLAB-based dynamic simulation of a three-phase induction motor operating under constant V/f control. The project analyzes motor speed, electromagnetic torque, and three-phase current responses during a 50 Hz to 40 Hz frequency transition.

## Objectives

- Model the dynamic behavior of a three-phase induction motor
- Implement constant V/f control for variable-speed operation
- Analyze transient and steady-state motor performance
- Study speed, torque, and three-phase current responses
- Generate engineering plots and export simulation data
